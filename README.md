# A Garden of Ideas

The UX/UI and product design portfolio of Zhinuo Wang, built with Next.js (App Router), TypeScript and Tailwind CSS.

```bash
npm install
npm run dev        # http://localhost:3000
npm run typecheck
npm run build
```

- `docs/PHASE-1-PLAN.md` covers the art direction, layout, interactions and missing-material checklist.
- `docs/ASSET-MANIFEST.md` maps every project image back to its original file.
- `src/data/projects.ts` holds all project content. Unknown fields stay `null` and are never invented.
- Decorative garden art lives in `src/components/garden/` and `public/assets/garden/`. Real project images live in `public/assets/projects/`.
